# Cyber Security Task 02 – Phishing Email Detection & Awareness

## 📌 Task Overview
This project focuses on analyzing phishing email samples and identifying common phishing indicators. The objective is to understand how phishing attacks work and create awareness guidelines to help users detect and avoid phishing emails.

This task simulates the role of a Security Analyst performing phishing email investigation and preparing an awareness report.

---

## 🎯 Objective

The main objectives of this task are:

- Analyze phishing email samples
- Identify phishing indicators
- Classify email risk levels
- Explain how phishing attacks work
- Provide prevention guidelines
- Create an awareness report for users

## 🔍 Analysis Approach

The phishing email samples were analyzed using the following steps:

1. Collected phishing email samples
2. Reviewed sender email addresses
3. Checked suspicious links and domains
4. Identified phishing indicators
5. Classified email risk level
6. Documented findings in a structured report
7. Provided prevention and awareness guidelines

---

## ⚠️ Phishing Indicators Identified

The following common phishing indicators were found:

- Suspicious sender email addresses
- Generic greetings (Dear User)
- Urgent and threatening language
- Suspicious links and domains
- Requests for sensitive information
- Fear-based messages

---

## 🛡️ Prevention Guidelines

To prevent phishing attacks:

- Always verify sender email addresses
- Avoid clicking unknown links
- Hover over links before clicking
- Enable Two-Factor Authentication (2FA)
- Avoid downloading unknown attachments
- Report suspicious emails immediately
